Ghost Draw

Politique de confidentialité

Les brouillons et dessins terminés sont conservés dans ce navigateur. Ils ne sont pas synchronisés automatiquement avec l'app iPhone ou un autre navigateur. Effacer les données du site les supprime.

Données stockées sur l'appareil

L'application peut stocker localement les dessins fantômes enregistrés, le texte des défis, les traits de dessin, les paramètres des cartes de partage et les favoris pour que la Galerie et le Replay fonctionnent.

Liens de replay cloud

Si vous créez un lien de replay, le service de partage de Ghost Draw stocke les données de replay du dessin et les quelques métadonnées nécessaires pour ouvrir le lien.

Partage

Lorsque vous utilisez la feuille de partage du système, vous contrôlez la destination de l'image exportée ou de la page de replay.

L'app offre une expérience de dessin native et une synchronisation iCloud facultative de la galerie. Le jeu web fonctionne seul ; installer l'app reste un choix.

Le partage d’un lien de relecture téléverse les traits, titres, commentaires et, éventuellement, une image d’aperçu. Toute personne ayant le lien peut les consulter. Les liens n’expirent pas automatiquement ; supprimer un dessin local ou iCloud ne retire pas le lien partagé. Contactez l’assistance pour demander son retrait.

Les propositions à la une incluent un identifiant de créateur aléatoire distinct pour mémoriser leur statut. Le pseudo apparaît seulement si vous activez l’attribution publique. Les mentions J’aime utilisent un autre identifiant aléatoire pour éviter les votes en double. Ces identifiants sont séparés de ceux des statistiques.

Statistiques d'utilisation

Activées par défaut. Nous enregistrons les actions de dessin, de révélation et de partage. Les identifiants aléatoires sont hachés avant stockage. Aucun dessin, titre, pseudonyme ou identifiant matériel n'est inclus. Désactiver arrête l'envoi et supprime les événements en attente.

Les événements d’utilisation sont conservés jusqu’à 90 jours. Vos liens publics de relecture ne sont pas concernés.

Les statistiques sont activées. Vous pouvez les désactiver dans Confidentialité et statistiques.

Désactiver les statistiques ne bloque pas les requêtes nécessaires aux relectures. Cloudflare peut traiter des informations techniques, dont les adresses IP et les erreurs, pour la sécurité et le fonctionnement ; elles ne figurent pas dans notre table d’événements.
