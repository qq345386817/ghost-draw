# Ghost Draw: 無料のブラインドお絵描きゲーム・毎日のお題

> ブラウザで無料のブラインドお絵描き。見えない線で自由に描き、毎日のお題に挑戦し、一筆ずつ公開。リプレイを友だちと共有できます。ダウンロード・登録不要。

線が見えないまま絵を描き、ゴーストを呼ぶと一筆ずつ現れます。毎日のお題や自由な発想で遊び、友だちにも同じお題を描いてもらいましょう。

ブラウザで遊ぶには JavaScript が必要です。ガイドを読むか、iPhone・iPad アプリを利用できます。

## ヘルプ

### 1. アイデアを選ぶ

自由に描くか、毎日のお題に挑戦しましょう。自由描画では作品名も付けられます。

### 2. 見えない線で描く

マウス・指・ペンで描けます。ポインターは動きますが、線は公開するまで見えません。

### 3. 自分の線を公開する

ゴーストを呼ぶと、描いた線が順番に再生されます。AI が代わりに作る画像ではありません。

### 4. 保存して共有する

公開した絵のデータはこのブラウザのギャラリーに保存されます。画像や公開リプレイのリンクを共有すると、友だちも同じお題に挑戦できます。

## AI が代わりに描いてくれますか？

いいえ。あなたが描いた線を記録して順番に再生します。別の画像を生成する機能ではありません。

## 絵はどこに保存されますか？

下書きと完成した絵は現在のブラウザに保存されます。iPhone アプリや別のブラウザには自動同期されません。サイトのデータを消すと絵も削除されます。

## 友だちも同じお題で遊べますか？

はい。共有リプレイから同じお題を開き、ログインせずに自分の絵を描けます。

## iPhone アプリとの違いは？

アプリはネイティブの描画体験と、任意の iCloud ギャラリー同期に対応します。ブラウザ版は単独で使え、アプリのインストールは任意です。

## このオンラインお絵描きゲームは無料ですか？

はい。ブラウザ版は無料で、ダウンロードも登録も不要です。自由描画・毎日のお題・ローカルギャラリー・リプレイ共有を利用できます。

## 友だちと同じお題で遊ぶには？

お題を描いてリプレイのリンクを送ると、友だちは同じお題を開いて自分の絵を描けます。同時に接続する対戦ルームではなく、別々のタイミングで遊ぶ形式です。

## プライバシーと統計

リプレイのリンクを共有すると、筆画・作品名・コメントと任意のプレビュー画像をアップロードします。リンクを知っている人は閲覧できます。リンクは自動失効せず、本機や iCloud の作品を削除しても共有リンクは取り消されません。削除の依頼はサポートにご連絡ください。

おすすめへの投稿には、投稿状況を記憶するための別のランダムな作成者 ID が含まれます。ニックネームは公開表示を有効にした場合のみ表示します。「いいね」は重複投票を防ぐ別のランダム ID を使います。これらの ID は利用統計の ID とは別です。

初期設定はオンです。描画・公開・共有などの操作を記録し、ランダムな識別子は保存前にハッシュ化します。絵・作品名・ニックネーム・機器のハードウェア識別子は含みません。オフにすると送信を停止し、未送信の記録を削除します。

利用状況の記録は最大90日間保存します。公開リプレイのリンクに有効期限を設けるものではありません。

統計をオフにしても、リプレイに必要な通信は停止しません。Cloudflare は安全性とサービス運用のために IP アドレスやエラーなどの技術情報を処理することがあります。これらは利用状況のイベント表には保存しません。
