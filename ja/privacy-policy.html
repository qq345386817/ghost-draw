プライバシーポリシー

下書きと完成した絵は現在のブラウザに保存されます。iPhone アプリや別のブラウザには自動同期されません。サイトのデータを消すと絵も削除されます。

デバイス上のデータ保存

ギャラリーやリプレイ機能を提供するため、アプリは保存されたゴーストの絵、プロンプトのテキスト、描画ストローク、シェアカードの設定、お気に入りをローカルに保存することがあります。

クラウドリプレイリンク

リプレイリンクを作成すると、Ghost Drawの共有サービスに、描画リプレイデータとリンクを開くために必要な最小限のメタデータが保存されます。

共有

システム共有シートを使用する場合、書き出された画像やリプレイページの送信先は、すべてあなたがコントロールします。

アプリはネイティブの描画体験と、任意の iCloud ギャラリー同期に対応します。ブラウザ版は単独で使え、アプリのインストールは任意です。

リプレイのリンクを共有すると、筆画・作品名・コメントと任意のプレビュー画像をアップロードします。リンクを知っている人は閲覧できます。リンクは自動失効せず、本機や iCloud の作品を削除しても共有リンクは取り消されません。削除の依頼はサポートにご連絡ください。

おすすめへの投稿には、投稿状況を記憶するための別のランダムな作成者 ID が含まれます。ニックネームは公開表示を有効にした場合のみ表示します。「いいね」は重複投票を防ぐ別のランダム ID を使います。これらの ID は利用統計の ID とは別です。

利用状況の統計

初期設定はオンです。描画・公開・共有などの操作を記録し、ランダムな識別子は保存前にハッシュ化します。絵・作品名・ニックネーム・機器のハードウェア識別子は含みません。オフにすると送信を停止し、未送信の記録を削除します。

利用状況の記録は最大90日間保存します。公開リプレイのリンクに有効期限を設けるものではありません。

利用状況の統計はオンです。「プライバシーと統計」で変更できます。

統計をオフにしても、リプレイに必要な通信は停止しません。Cloudflare は安全性とサービス運用のために IP アドレスやエラーなどの技術情報を処理することがあります。これらは利用状況のイベント表には保存しません。
